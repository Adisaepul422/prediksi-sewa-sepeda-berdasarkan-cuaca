Cara membaca model

cnt = {{ ringkasan.beta0|ribuan(2) }} + {{ ringkasan.beta1|ribuan(2) }} × temp, dengan temp = suhu °C ÷ {{ pembagi|int }}.

  • Setiap kenaikan 1 °C, penyewaan diprediksi naik sekitar {{ (ringkasan.beta1 / pembagi)|ribuan(0) }} sepeda per hari.
  • Intersep ({{ ringkasan.beta0|ribuan(0) }}) adalah titik awal garis pada temp = 0 (sekitar 0 °C), bukan prediksi yang bermakna untuk hari biasa.
  • Model hanya memakai suhu. Musim, cuaca, dan hari kerja juga berpengaruh, jadi hasilnya perkiraan kasar.
